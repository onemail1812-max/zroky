# Feature-by-Feature Matrix: Aaliyah (Zroky) vs. Eva (Marblism)

This document provides a technical and operational breakdown of why **Aaliyah** is the superior "Masterpiece" architecture for high-stakes executive support, compared to the commodity offering of Marblism's **Eva**.

## 1. Intelligence & Memory Root
| Feature | Eva (Marblism) | Aaliyah (Zroky) | The "Better" Factor |
| :--- | :--- | :--- | :--- |
| **Memory Architecture** | Session-based / Basic RAG | **Double-State (Hot/Cold)** | Aaliyah retains long-term context (Cold) while processing immediate requests (Hot). |
| **Knowledge Graph** | None (Static Context) | **Dynamic Graph Facade** | Aaliyah maps relationships between people, projects, and high-stakes intents. |
| **Contextual IQ** | Reactive (responds to input) | **Proactive (anticipates needs)** | Aaliyah uses memory to predict VIP needs before they are explicitly messaged. |

## 2. Inboxes & Triage (The "Eye")
| Feature | Eva (Marblism) | Aaliyah (Zroky) | The "Better" Factor |
| :--- | :--- | :--- | :--- |
| **Multi-Provider Sync** | Standard OIDC Connect | **Async Parallel Sync** | Aaliyah uses high-performance `gather` patterns for Gmail/Outlook sync. |
| **Smart Labeling** | Basic categorization | **Persona-Based Triage** | Labels are applied based on *your* specific taxonomy and executive priorities. |
| **Noise Filtering** | Archive-all approach | **Intelligent Suppression** | Aaliyah differentiates between "Newsletter" and "Opportunity" with high precision. |
| **Action Log** | Not visible | **Unified Transparency Feed** | Every label, archive, and draft is visible in a live "Intelligence Feed." |

## 3. Scheduling & Calendar (The "Time Lord")
| Feature | Eva (Marblism) | Aaliyah (Zroky) | The "Better" Factor |
| :--- | :--- | :--- | :--- |

| **Negotiation Flow** | "Send a link" | **Dynamic Slot Injection** | Aaliyah handles the back-and-forth natively within the email draft. |
| **Booking Pages** | Generic/Third-party | **Ephemeral Workspace Pages** | Aaliyah creates one-click, branded booking pages for your recipients. |
